# Lovie Homebrew Tap

Homebrew formulae for [Lovie](https://lovie.co) command-line tools.

## Install

```sh
brew install lovieco/tap/lovie-cli
```

Or tap first, then install:

```sh
brew tap lovieco/tap
brew install lovie-cli
```

This installs the `lovie` command.

## Upgrade

```sh
brew upgrade lovie-cli
```

## Uninstall

```sh
brew uninstall lovie-cli
brew untap lovieco/tap
```

## What is `lovie`?

`lovie` is a single-binary command-line tool for working with your Lovie account
straight from your terminal. Run `lovie --help` to get started.

Learn more at [lovie.co](https://lovie.co).
